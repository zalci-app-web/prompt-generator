# AI Prompt Generator

プロ級のAIプロンプトを簡単に生成できるツール

## 🚀 特徴

- **3つのモード**: Lite（初心者）、Normal（標準）、Hard（上級者）に対応
- **リアルタイムプレビュー**: 入力と同時にプロンプトを生成
- **ワンクリックコピー**: 生成されたプロンプトを即座にクリップボードにコピー
- **ダークモードUI**: 目に優しいモダンなデザイン

## ✨ 各モードの特徴

### Lite Mode (初心者向け) ⚡
- 最小限の入力項目
- 質問内容を入力するだけで使用可能
- 汎用的なプロンプトを自動生成

### Normal Mode (標準) ✓
- 専門家ロールをドロップダウンで選択
- デザインパターンを選択式で指定
- 参照元や調査済み内容を追加可能

### Hard Mode (上級者向け) 🔬
- 詳細な開発環境の指定
  - 言語・バージョン（C++23, Python 3.12など）
  - ライブラリ・フレームワーク（Unity 6, Unreal Engine 5.4など）
- コーディング規約の指定
  - 命名規則
  - コメントの有無
  - 参照禁止サイト
- エラーハンドリングとデバッグ処理の方針

## 🛠️ 技術スタック

- **HTML5**: セマンティックなマークアップ
- **CSS3**: Tailwind CSS (CDN) を使用したモダンなスタイリング
- **Vanilla JavaScript**: フレームワーク不要、軽量で高速

## 📦 ファイル構成

```
PromptAI/
├── index.html       # メインHTMLファイル
├── styles.css       # カスタムスタイル
├── app.js           # プロンプト生成ロジック
└── README.md        # このファイル
```

## 🚀 使い方

1. **モードを選択**
   - 画面上部のタブから Lite / Normal / Hard を選択

2. **情報を入力**
   - 各モードに応じた入力フォームに記入
   - リアルタイムでプロンプトが右側に生成されます

3. **プロンプトをコピー**
   - 「コピー」ボタンをクリック、またはCtrl+Enterで一発コピー
   - AIチャット（ChatGPT、Claudeなど）に貼り付けて使用

## ⚠️ 重要な注意事項

**個人情報の入力、会社、学校内の情報の入力はしないでください**

このツールはクライアントサイドのみで動作し、データがサーバーに送信されることはありませんが、セキュリティのため機密情報の入力は避けてください。
